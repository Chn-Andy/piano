# Grill：主题曲《猪侠漫游记》——全轨伴奏 + 主题色 + 动物化怪物

> 访谈决策文档。规则：每轮只问「前置已定」的决策；答完一轮先落文档再问下一轮。
> 关联：ADR-0016（伴奏只承担和声）、ADR-0018（试作曲入库）、ADR-0005（水墨方向）。

## Facts（先量后问）

- **F1 音频底座**：`src/audio/engine.ts` 用 `AudioContext.currentTime` 作唯一主时钟；`pause()` 挂起上下文（音轨会随上下文冻结）；只有 music / sfx 两条总线；**当前没有任何常驻音轨**。`src/audio/piano.ts` 只加载 5 个钢琴采样（C4 / Ds4 / Fs4 / A4 / C5）。
- **F2 这首歌的谱面**：`src/charts/zhuxia/*.json` —— easy 97 音符（0.72 音符/秒）、medium 130（0.96）、hard 195（1.44）；时长 137.6s；伴奏声部 139 / 418 / 557 音。源 MIDI 为 228 个旋律音 + 139 个和弦事件（每两拍一个根音+三音）。
- **F3 原曲与时间原点**：视频音轨 148.0s；MIDI 由 2.8s 起截取；谱面时间原点 = 第一颗音 − `LEAD_IN_SECONDS` = 原曲 **2.776s**（不是 2.8s）。原曲 123 BPM，Bb 大调。
- **F4 难度移调**：easy 走 `whiteKeyTranspose(Bb 大调)` = **+2 半音到 C**（只弹 7 白键）；medium/hard 不移调，仍是 Bb。原曲伴奏是 Bb —— 所以 **easy 与全轨伴奏差 2 个半音**，这是硬冲突，不是混音能救的。
- **F5 转谱时间精度**：pyin 音符起点与视频人声 onset 峰对比，**47% 落在 60ms 内、76% 落在 120ms 内**；hard 网格 0.122s、medium 0.244s、easy 0.488s。全轨人声会把转谱的偏音/偏时暴露出来（尤其 easy/medium）。
- **F6 渲染底座**：`src/render/renderer.ts` 单文件 canvas。纸/墨/深墨写死为 `PAPER #efe9dc` / `INK #37322a` / `DEEP_INK #1d1a15`（204–208 行）；怪物形貌是 `drawGhoul`（935 行起，人形刺客：斗笠、蒙面、执刀）与 `drawMonster`（1162 行起）；`MonsterKind = 'inkDemon' | 'inkLord'`；渲染模型没有主题参数。渲染器里 14 个硬编码色值，`index.html` 里约 20 个；HUD 在 canvas，菜单/结算在 DOM。
- **F7 纪录与回放**：`src/core/records.ts` 每曲每难度存最佳评级/连击/精度/零失误精度；回放「听我的演奏」取最后 20s，只响钢琴与伴奏，不写存储；结算入册。
- **F8 设置**：只有 `musicVolume` / `sfxVolume`，没有伴奏或人声音量。
- **F9 体积**：dist JS 243KB；钢琴采样约 0.9MB；原曲 3.1MB（192k MP3）。`assets/` 是 publicDir。
- **F10 视频主色**：第 3 帧量化统计，深绿 `#105020` 占 63.1%，粉色 `#f0c0c0` 约 1.4%；插画是深绿田野 + 粉猪 + 木栅栏。
- **F11 测试**：388 项全绿；渲染层只有几何测试，没有像素测试；定标 48 项（四曲 × 三难度）。

## Decisions

**Round 0（用户直接指定，尚未细化）**

- **D1**：这首歌用**原曲全轨（含人声）**作为战斗音轨，不是器乐-only。落点：本文件；ADR-0019 待写。
- **D2**：弹这首歌时，战斗**主题色改变**。落点：本文件；ADR-0019 待写。
- **D3**：这场斗琴里的**怪物变成动物**（视觉；用户原话「仅供怪物也变成动物」按「并且怪物也变成动物」理解）。落点：本文件；ADR-0019 待写。

**Round 1（2026-11-05）**

- **D4（Q1）**：玩家弹**同一条旋律**——钢琴与人声齐奏，人声当引导；保留现有转谱谱面，不重编和声/副旋律。落点：本文件；实现走现有 `zhuxia` 谱面。
- **D5（Q2）**：全轨只在 **medium / hard** 开启；**easy 保持纯钢琴版**（easy 的 +2 半音移调不动，避免与 Bb 原曲差 2 个半音的硬冲突）。落点：本文件；`SongEntry` 需要按难度区分音轨。
- **D6（Q3 → Q10 改选 c，已推翻）**：全轨模式**照常计入正式纪录**——结算显示评级 + 判定，曲库徽记正常更新。原先「不计入、也不新增标记」的版本作废；用户接受人声作为 timing guide 带来的难度下降。落点：本文件；`records.ts` 的写入路径**不跳过**全轨局。
- **D7（Q4）**：主题色**只作用于战斗画面**（弹奏这首歌时）；菜单、结算、曲库、其他歌都不变。落点：本文件；主题只进 canvas，不进 DOM/CSS。
- **D8（Q5）**：主题色方向 = **浅绿纸 + 墨绿线 + 粉/黄点缀**，保留水墨的明度关系；深绿底 + 纸白墨线的版本留作二版。落点：本文件；具体色值见 Round 3 的配色稿。
- **D9（Q6，override）**：怪物改成**可爱风**——用户推翻了我推荐的「水墨剪影动物」。具体画法与动物阵容见 Round 2。落点：本文件；`drawGhoul` 需要换一套形貌。

**Round 2（2026-11-05）**

- **D10（Q7）**：可爱风走**水墨可爱**——保留墨色剪影材质，圆身、短腿、纸白大眼、粉腮红；不改成彩色卡通，D8 的浅绿纸 + 墨线主题成立。落点：本文件；渲染层新增可爱动物形貌，材质仍是墨。
- **D11（Q8）**：动物阵容 = **山贼动物：野猪 / 狐狸 / 狼**；墨主 = **带刀疤与玫瑰的野猪王**（呼应歌词「刀疤带着玫瑰花」）。行为、数值、定标不变。落点：本文件；`MonsterKind` 不改，只在渲染层按 id 选物种。
- **D12（Q9）**：全轨人声**固定比钢琴低 3dB**，不做逐音闪避。落点：本文件；音频层给全轨一条独立增益。
- **D13（Q10，override）**：结算**显示评级 + 判定**，并**照常入册**；D6 作废。落点：本文件；records 正常写入。
- **D14（Q11）**：全轨**随游戏公开发布**（GitHub Pages + itch 都带）。落点：本文件；README/itch 加素材来源。
- **D15（Q12）**：配色 = **A 的绿 + C 的粉**——纸/墨用 A 的色相，粉色强调用 C 的 `#e08fa5`，金色用 A 的 `#d9ad55`。实机把纸色加深到 **`#dce8cd`**（A 稿的 `#e9f0e2` 被纸纹的高光洗成灰白，实测偏灰）；墨 `#25332b`、深墨 `#16211b`。落点：本文件；实现走 `BattleTheme` 调色板。
- **D16（署名修正）**：公开署名 = **心心念念**（不带方括号；去掉「豆包 AI」的并列署名）。README 的技术来源段仍可如实写「AI 生成」，但不进公开署名的并列位。落点：本文件；README/itch/曲库页面。

> **Override 记录**：Q10 选 c，推翻了 Q3 的「不计入纪录」；人声被接受为合法的 timing guide，全轨局与钢琴局在同一个 mastery 阶梯里比较。

## Implementation defaults（可逆，我先定下，用户可随时推翻）

- **物种映射**：墨妖按 `monster.id` 的哈希分到野猪 / 狐狸 / 狼三种形貌；墨主固定为刀疤野猪王。行为、HP、定标完全不动。
- **主题进场/退场**：倒计时期间 0.8s 淡入；终局（结算出现）0.6s 淡出回纸白。暂停面板保持纸白（D7 的「其他不变」）。
- **回放**：回放静音全轨，只响钢琴 + 伴奏——「听我的演奏」听的仍是自己弹的。
- **加载失败**：全轨加载失败时降级为纯钢琴版，不阻塞开局；控制台警告，不加弹窗。
- **曲库标示**：medium / hard 的难度格加一枚小「原曲」签；easy 不加。blurb 改为「主题曲 · 原创」/「Theme song · Original」。
- **素材署名**：README 的 fixture/素材段与 itch 描述加「《猪侠漫游记》— 心心念念 / 豆包 AI 生成」；音频文件进 `assets/songs/`。
- **动物不命名**：游戏不显示怪物名，也不新增 GLOSSARY 词条；死亡仍是墨溅（可爱风只改形貌，不改材质/行为）。
- **不做主题开关**：这首歌永远开主题；其他歌不受影响。
