# 08: 怪物推进与掉血归因重构

**What to build:** 战场活起来：墨妖不再是站桩靶，而成群自战场深处向琴阵推进（横向散布、生成确定性、难度决定节奏）；抵达琴阵后每 2 拍咬一口直到被杀。miss 不再直接扣血——只留剑气扑空与怪物突进的可见反馈，血量威胁完全来自怪物到位。剑气改为全屏纵深衰减 AoE：每次命中打击全场怪物，前排承伤最多、后排逐级递减。余韵/终章升格为真实 AoE 伤害事件（表现分加成，终章 grand 须能斩首墨主）。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 怪物成群生成并向琴阵推进：横向散布、确定性（同曲重开一致）、生成节奏随难度；上半区渲染多怪纵深排布
- [ ] 怪物抵达琴阵后每 2 拍攻击一次（约 10 血/口，常量集中）直至被杀；被击杀时从战场移除
- [ ] miss/漏音符不再直接扣血；保留扑空视觉反馈；玩家血量仅因怪物攻击下降
- [ ] 剑气=全屏纵深衰减 AoE：衰减比与纵深上限为集中常量；怪物横向位置不构成目标语义
- [ ] 余韵/终章按表现分对全场造成真实 AoE 伤害；终章（grand）可击杀墨主
- [ ] 胜负面不变：撑到歌末且清空全场（含墨主）为胜、血空为败
- [ ] Seam 1 战斗测试按新模型重写（推进/到线攻击/AoE 衰减/词缀前 battlefield 语义/胜负/确定性），既有谱面/判定/余韵/评级测试零回归
- [ ] v1 战斗数值（HP 公式等）随 AoE 模型重定标进 config 并在注释给出定标理由
