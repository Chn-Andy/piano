## Comments

**2026-10-27 · 重做并关票**：`src/render/renderer.ts` 的 `drawMonster` 拆成 `drawGhoul`（形貌）+ `inkSplatPath`（墨团轮廓含墨刺）。

**设计过程（试了 6 版，写下来免得下次重走）**：

| 版本 | 做法 | 为什么不行 |
|---|---|---|
| v1（原版） | 平滑多边形墨团 + 两道纸色短划 | 读成「石头上有两道划痕」 |
| v2 | 斗篷 + 圆头 + 白眼 | 读成猫头鹰 |
| v3 | 纸面具 + 墨眼（大白脸） | 大白脸=卡通 |
| v4 | 瘦高带刺剪影 | 刺对了，但眼缝位置落在胸口 |
| v5 | 加颈分头肩 | 头太小，眼睛被吞 |
| v6–v9 | 面罩带 + 各种下摆 | 面罩对了，下摆出现「两条腿」 |
| **v10–v13（采用）** | **墨团 + 墨刺 + 粗墨尾 + 窄面罩（同向眼缝）** | 小尺寸也读得出「戴面具的墨鬼」 |

**关键裁定**：
1. **脸要窄、五官要少**：一条纸色面罩横在上半身，里面两道同向细缝——镜像的两道会合成一条白带（读成嘴）。
2. **外形要刺**：墨团外缘插 6–7 根长短不一的墨刺（墨点飞溅凝住的瞬间），别做对称人形。
3. **墨主 = 唯一「更大更凶」的那只**：体积 ×1.2、双角、面具朱砂竖纹、腰间符纸；墨妖保持无脸（只有面罩）。
4. **远近有神态**：`aggro = 1 - 纵深比`，越贴琴阵眼缝越睁、口越开（墨主另加）。
5. 血条下移到墨尾之外，避免压住形貌。

体积：drawGhoul 约 200 行 + inkSplatPath 40 行，无新增素材、无新增依赖；产物 137.4 KB（+3.6 KB）。
