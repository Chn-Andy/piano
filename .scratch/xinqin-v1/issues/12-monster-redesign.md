# 12: 墨妖/墨主形貌重做——墨色刺客

**What to build:** 用户试玩反馈「怪物的样子太差了」，随后补一句更关键的：「能不能更像人一点？可以把这个想象成刺客，我通过琴声来杀敌」。

所以形貌的目标不是「怪物」，而是**人**：一具墨色的刺客剪影——斗笠/兜帽、蒙面、执刀、瘦高、正朝你走来；琴声是唯一的武器，你得在他们够到琴阵之前杀掉他们。仍然零美术素材、纯 Canvas 程序绘制、帧间确定性（同一只怪每帧同一副姿态）。

**Blocked by:** None

**Status:** resolved

- [x] 人形比例：头（半径 0.36w）、颈、肩（0.95w）、束腰（0.46w）、长衫开衩、前后错开的两条腿
- [x] 刺客读法：右手横刀（刀身有宽度、护手、刃口纸色反光），刀随 aggro 抬起
- [x] 蒙面：一条纸带横遮双眼，随头微斜
- [x] 墨主：高 1.24 倍、宽斗笠、更长的刀、腰间一道朱砂带——剪影上一眼可分
- [x] 状态可读性不变：寒音青霜环、毒音苍绿斑、爆音闪烁、挨咬红晕、血条都在
- [x] 帧间确定性：同一 id 同一姿态，只有呼吸/摇摆/墨滴随时间动
- [x] 测试与构建全绿（222/222）

## Comments

**2026-10-28 · 重做并关票**：`drawMonster` → `drawGhoul`（形貌）；尺寸常量在函数头注释里（身高 2.0h、肩宽 0.95w、腰 0.46w，h = r）。

**两轮设计（试了 16 版，把走错的路记下来）**：

| 阶段 | 做法 | 结果 |
|---|---|---|
| v1（原版） | 平滑多边形墨团 + 两道纸色短划 | 读成「石头上有划痕」 |
| v2–v9 | 斗篷/猫头鹰/大白脸/带刺墨团/窄面罩…… | 都像「怪物」，不是「人」——用户一句话点破了：*能不能更像人一点？* |
| v10–v13 | 墨团 + 墨刺 + 面罩带（墨鬼） | 好于原版，但仍非人形 |
| **v14–v16（采用）** | **人形刺客：头/颈/肩/腰/腿 + 横刀 + 蒙面纸带；墨主加斗笠与朱砂带** | 一眼读作「刺客」，符合「你弹琴、他来杀你」的幻想 |

**关键裁定**：
1. **先认人、再认刺客**：头必须是一个分明的圆、颈要细、肩要展开、腰要收——`v14` 的头埋进肩里，看起来像斗篷团；`v15` 拉出颈与头才立起来。
2. **刀是第二读法**：刀身要有宽度与护手，只画一条线会读成「杆子」。
3. **蒙面纸带留在脸上**：位置在头中心，宽度略窄于头（0.3w），随头微斜——宽了像发带，白了像绷带。
4. **墨主不做人形的夸张**：不加大角（那是妖怪），改**斗笠 + 更长的刀 + 朱砂腰带**——更「人」的 boss 更吓人。
5. 姿态随机但稳定：`hash2(id)` 决定歪斜、刀的初始角度；`aggro = 1 − 纵深比` 决定刀抬多高。
