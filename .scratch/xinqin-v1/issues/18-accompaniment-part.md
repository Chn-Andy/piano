# 18: 伴奏声部——曲子始终在，旋律永远是你的

**What to build:** 每首曲子都有一层和声骨架在下面持续演奏（左手/低音），玩家只负责主旋律：
曲子不再因为你漏音而断掉，但漏掉的那颗音**不会被代弹**（ADR-0016）。伴奏由转换器从源曲的非主旋律材料
确定性生成，写进谱面契约；播放走既有的音频主时钟 lookahead 调度器，与琴声共用「琴声音量」，
不新增录音素材。密度按难度分档（简单：低音 + 根音；中等：三和弦分解；高级：补内声部），
不随表现动态加厚。卡农的源 MIDI 只有单轨、没有可拆材料，这一版用引擎合成的低频铺底兜底，
**不替换 fixture、不改卡农谱面**。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 一首曲子从开演起就有伴奏：整首内任意 4 秒窗口里至少有一声伴奏音（卡农的合成铺底同样满足）
- [ ] 试听验收：卡农 / 致爱丽丝 / 春江花月夜各听 ≥15 秒，不按键也能听出是那首曲子
- [ ] 不代弹：同一时刻、同一音高的音不得同时出现在旋律与伴奏中（转换器结构测试锁定）
- [ ] 静置对局（不按任何键）时只听到伴奏、旋律全程不响——证明漏音不被补
- [ ] 同一曲目的伴奏密度随难度单调（简单 ≤ 中等 ≤ 高级 的每分钟伴奏音数）
- [ ] 伴奏不进判定、不产生任何战斗事件、不改任何定标：全量测试与三曲 × 三难度 × 三玩家模型的 36 项性质保持绿
- [ ] 卡农用合成低频铺底，且重生成后的卡农谱面与现版本逐字节一致（谱面不动）
- [ ] 致爱丽丝用左手声部派生伴奏、春江花月夜用第二条旋律声部派生伴奏
- [ ] 设置里的「琴声音量」同时作用于伴奏；调到 0 时伴奏与琴声一并静音，战斗音效不受影响
- [ ] 旧谱面（没有伴奏声部字段）仍能加载并静默跳过，不报错、不崩
- [ ] 重复生成同一 fixture 的伴奏结果一致（确定性，可哈希比对）
- [ ] 全量测试与构建绿；`docs/calibration.md` 的定标数值一个都不变
