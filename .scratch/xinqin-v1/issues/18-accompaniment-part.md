# 18: 伴奏声部——曲子始终在，旋律永远是你的

**What to build:** 每首曲子都有一层和声骨架在下面持续演奏（左手/低音），玩家只负责主旋律：
曲子不再因为你漏音而断掉，但漏掉的那颗音**不会被代弹**（ADR-0016）。伴奏由转换器从源曲的非主旋律材料
确定性生成，写进谱面契约；播放走既有的音频主时钟 lookahead 调度器，与琴声共用「琴声音量」，
不新增录音素材。密度按难度分档（简单：低音 + 根音；中等：三和弦分解；高级：补内声部），
不随表现动态加厚。卡农的源 MIDI 只有单轨、没有可拆材料，这一版用引擎合成的低频铺底兜底，
**不替换 fixture、不改卡农谱面**。

## Comments

**2026-10-31 · 实现记录（分支 `ticket/18-accompaniment`）**

### 1. 怎么判定「非主旋律」

`parseMidi` 现在把分轨带出来（`SourceTrack`：轨号 / 轨名 / 通道 / 是否打击轨 / 音数），
音符上带所属轨号。转换器按**文件书写顺序**取第一条有音的旋律轨为主旋律、**第二条**为伴奏材料：
MIDI 的惯例是右手（`up:` / `Solo`）在前、左手或第二旋律声部在后，打击轨（通道 9）永远排除。

| 曲目 | 轨道 | 主旋律 | 伴奏材料 |
| --- | --- | --- | --- |
| 卡农 | 单轨 138 音 | 唯一轨 | **无** → 合成低频铺底 |
| 致爱丽丝 | `up:` 517 / `down:` 388 | `up:` | `down:`（左手） |
| 春江花月夜 | `Solo` 547 / koto 532 / `Drum` 3 | `Solo` | koto（第二旋律声部，107.4s 起才进） |

也试过「按平均音高最大者为主旋律」——春江的 koto 平均音高反而更高（61.2 vs 60.4），
会把它误判成旋律，故改用书写顺序。

### 2. 三档织体与音域

和声窗口 = 2 拍（60bpm 两秒、72bpm 1.67 秒），窗内声部数按难度分档，**不随表现加厚**：

- 简单：1 声，窗内材料的最低音（左手根音）；
- 中等：3 声，低音 + 三度 + 五度的分解（三度性质取自窗内材料音级，听不出时按调号兜底：
  a 小调配小三度——否则会一直把 C 弹成 C#）；
- 高级：4 声，再补一条内声部（材料里除根/三/五之外最靠近低音的音级；材料只有三和弦时补八度）。

音域：伴奏折进「旋律最低键之下两个八度」的左手音域（简单/中等 C2..B3、高级 G2..F#3 一带），
**任何时刻都低于玩家能按出的每一个音**——这是「不代弹」的第一道闸；第二道闸是谱面契约
`validateAccompaniment`：同刻同音高直接拒绝装配（测试同时钉住这条结构性质）。

### 3. 材料沉默的段落

春江花月夜前 107 秒只有 `Solo` 在唱、koto 还没进；致爱丽丝曲末也有收尾余量。
这些窗口没有材料可用，转换器用 `core/pad.ts` 的合成铺底顶上（每 2 秒一换和声，
根音取该窗旋律最低音的音级，落在旋律键域之下一个八度；简单 1 声 / 中等 2 声 / 高级 3 声）。
铺底不取主旋律的音高，只取它的**和声根音**并整体搬到更低的音域，故不是「拿主旋律冒充伴奏」。

### 4. 卡农：谱面一个字节都没动

单轨 138 音、没有可拆材料 → `buildAccompaniment` 返回 `undefined`，转换器不写伴奏字段，
`src/charts/canon/*.json` 重生成后逐字节不变（测试里钉了三份 JSON 的 sha256，
值取自改动前的产物：`f89c1f3f…` / `6db5ef07…` / `27b66378…`）。
铺底改在运行时由 `core/accompaniment.ts` 的 `accompanimentPlan(chart, 'pad')` 生成，
经同一个 lookahead 调度器、同一套钢琴采样发声——没有新的音频代码、没有新素材。
「某曲没有伴奏字段时要不要铺底」由曲目条目显式声明（`SongEntry.accompanimentFallback`，
只有卡农写了 `'pad'`），所以旧谱面（无字段、无声明）是静默跳过而不是被塞一层铺底。

### 7. 未验证 / 遗留风险

- **两条听感项如实留空未勾**：「各听 ≥15 秒能听出是那首曲子」与「静置对局只听到伴奏、旋律不响」——
  实现上后者的路径是明确的（伴奏不经按键管线、不进模拟器，`?auto=idle` 全程无琴声），但耳朵的判断留给人。
- 听感风险（供试听时重点听）：①铺底把钢琴采样下移一个八度重采样（C3 一带 rate 0.5），音色偏闷；
  ②高级每窗 4 声、春江 111 音/分钟的伴奏密度可能偏忙，混音上需要「压住但不抢」；
  ③春江前 107 秒只有铺底（材料本身缺席），听感会比后段空。
- 音频节点图按项目口径不写自动化测试：伴奏与琴声共用 `musicBus` 是靠同一 `Piano` 实例保证的，
  「调到 0 一并静音」由增益节点直接成立，未做节点图断言。
