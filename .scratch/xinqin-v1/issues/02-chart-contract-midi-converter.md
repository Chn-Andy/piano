# 02: 谱面契约与 MIDI→谱面转换器

**What to build:** 把"多首歌 × 三难度"从手工劳动变成规则问题：确立谱面 JSON 契约（音符、乐句边界、余韵窗口、难度元数据），实现构建期转换器，将公版 MIDI（以卡农为首例）一键转出三难度谱面。转换器是项目核心资产（ADR-0003），其结构性质由 Seam 2 测试锁定。

**Blocked by:** 01（谱面契约以 01 的最小谱面为种子扩展，避免双源定义）

**Status:** ready-for-agent

- [ ] 谱面 JSON 含音符（时刻/键位/和弦分组）、乐句边界、余韵窗口、难度元数据
- [ ] 卡农公版 MIDI 一键转出简单/中等/高级三份谱面
- [ ] Seam 2 结构测试通过：三难度键位范围正确（7 白键 / 12 键 / 扩域）、余韵窗口内无音符、难度间密度单调、乐句边界存在、和弦分组合法
- [ ] 难度规则（量化网格、密度过滤、和弦识别、休止切分）为集中常量，定标可调
