# 13: 刺客动作——走、举刀、挥砍

**What to build:** 用户的意见：「要真的在攻击我，是要动的刺客，不是一张图纸」。给墨妖/墨主加上动作：推进时**迈步走**（双腿交替、身体起伏、衣角飘），到琴阵后收成弓步，**咬人前举刀、咬中时劈下并甩出刀光**。全部由时间相位与模拟器事件驱动，帧间可复现（渲染层仍无状态）。

**Blocked by:** 12

**Status:** resolved

- [x] 前摇：距下一口咬击 < 0.34s 时刀缓缓抬起——**掉血之前**先看见他要动手

## Comments

**2026-10-28 · 关票**：`MonsterView.nextBiteAt` + 渲染层 `MonsterAnim { moving, step, windup, slash }`。

**动画参数（都在渲染层，改起来是三个数）**：

| 参数 | 位置 | 现值 | 说明 |
|---|---|---|---|
| 步频 | `drawMonster` 的 `step = t * 1.7` | 1.7 步/秒 | 推进速度 0.53 度/秒时的步幅观感 |
| 前摇窗 | `windup = (0.34 − untilBite) / 0.34` | 0.34 秒 | 咬击前 0.34 秒开始举刀 |
| 挥砍跟随 | `slash` 取 `m.bites` 后 0.24 秒 | 0.24 秒 | 刀劈下 + 纸色刀光的持续时间 |
| 抬手/压手幅度 | `handLift`、`bladeAngle` | 0.14h / 0.7 与 1.25 rad | 前摇抬多高、劈得多狠 |

**验证方式**（`.devtools/` 里的工具，可复跑）：
- `node .devtools/closeup.mjs 20.7 5` —— 咬击前后每 95ms 一张 2.2× 特写：举刀 → 劈下 → 收势；
- `node .devtools/closeup-walk.mjs 9.4 4 110` —— 推进期特写：双腿交替；
- 确定性：同一 id 同一相位永远同一帧，暂停后重放一致。

**取舍**：动画全部由 `t` 与事件相位算出，不加粒子状态机——渲染层仍然无状态、可重放；代价是「举刀」只能按排定的咬击时刻预告（寒音把它推开时，前摇会随 nextBiteAt 一起顺延，正是想要的效果）。
