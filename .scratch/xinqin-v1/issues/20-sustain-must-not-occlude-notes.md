# 20: 余韵不许遮住音符

**What to build:** 余韵/终章演出播放时，下落的音符必须照常可见、照常下落。原实现把音符画在演出**之下**，并且在余韵窗口内把音符冻结在窗口起点、透明度按「溶解→凝出」包络降到 0——窗口有 1.5–2.5 秒，正好是下一批音进入视线的时刻，于是玩家在那一秒多里看不见任何音（用户反馈：「触发余韵的时候会遮盖所有的音符」）。改为：音符层画在战场与演出之上，窗口内不冻结、不淡出；轨道染色与判定线仍会随窗口收淡（那是演出让位，不夺读谱）。ADR-0007 的「暂停音符下落」随之被取代。

**Blocked by:** None

**Status:** resolved

- [x] 音符在余韵与终章演出期间照常下落、保持满不透明（不再有「溶解→凝出」包络）
- [x] 音符绘制层移到余韵/终章演出之外、之上；HUD 仍在最上层
- [x] 演出本体（墨晕、剑气笔势、墨点、题字、朱砂印、闪帧、四角垂墨）全部保留，只是不再盖住音符
- [x] 判定与战斗数值零改动（判定仍是时间判定，音符位置公式不变）
- [x] ADR-0007 增补：暂停音符下落被取代，并写明原因
- [x] 浏览器实测：余韵窗口内截图可见下落音符且位于墨爆之上（1440×900，`?auto=perfect&song=fur-elise&chart=medium`，t=104.4 剑鸣）
- [x] `npm test` 349/349 绿、`npm run build` 绿
