# 09: 异色音符（寒音/毒音/爆音）

**What to build:** 下落音符偶发异色：转换器为谱面确定性编排词缀（频率约 5–8%，三色加权，同曲重开布局一致），命中照常结伤并附加战场效果——🔵寒音：全场怪物击退半步并减速 3 秒；🟢毒音：最前怪中毒每拍掉血持续 5 秒；🔴爆音：对最前与次前怪物重击。轨道染色、命中特效与合成音效随色区分。

**Blocked by:** 08

**Status:** ready-for-agent

- [ ] 谱面契约扩展词缀字段；转换器按集中常量（频率/加权/最小间隔）确定性分配，Seam 2 结构测试锁定（频率区间、确定性、三难度可见）
- [ ] 寒音/毒音/爆音三效果在模拟器纯层实现（持续时间/伤害为集中常量），Seam 1 测试锁定（含与 AoE 衰减的叠加语义、无怪在场时效果扑空不崩溃）
- [ ] 异色音符照常参与判定与连击（词缀不改变判定难度）
- [ ] 渲染：轨道/音符着色、命中特效按色区分、怪物减速/中毒/受爆的可见状态
- [ ] 三色合成音效接入（与既有战斗音效分层）
