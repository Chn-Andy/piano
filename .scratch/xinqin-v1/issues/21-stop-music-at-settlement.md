# 21: 终局画面出现时音乐必须停

**What to build:** 一局结束（血尽或歌末清场）掀开结算画面时，伴奏声部要立刻收声：丢弃所有未到期的调度，并把音乐轨在约 0.35 秒内淡出（正在响的采样随总线一起消失，不硬掐、不爆音）。离开结算回曲库不再需要额外处理；开新局时把音乐轨恢复到设置音量，绝不能出现「第二局静音」。

**Blocked by:** None（伴奏声部落地后才暴露的问题）

**Status:** resolved

- [x] 结算画面出现的那一刻清空调度队列，并在 0.35 秒内把音乐轨淡出
- [x] 实测：结算出现后 6 秒内没有任何新的伴奏发声（修前每 2.0 秒一次）
- [x] 「听我的演奏」仍然有声：重放先恢复音乐轨再排音（修前若只淡出而不恢复，回放会变哑）
- [x] 从结算回曲库后开新局，伴奏照常（音乐轨已恢复，实测 8 秒内 6 次发声）

## Comments

**2026-11-01 · 开票与修复同批**

用户提问：「如果失败了停在结束画面那，音乐是不是没有停下来？」——**是没停**。

根因：伴奏在开局时**整首一次性**排进 lookahead 队列（`scheduleAccompaniment`），而清队列只发生在
「放弃对局 / 回曲库 / 停回放」三处；终局那刻没人清，泵就继续按点把伴奏音符发出来。修前实测：
结算出现后 6 秒内多出 3 次发声，间隔恒定 2000ms（卡农铺底的两秒一拍）。

修法：`AudioEngine` 新增 `fadeOutMusic(0.35)`（清队列 + 总线线性淡出）与 `restoreMusic()`（恢复设置音量）；
`showSettlement()` 调前者，`beginBattle()` 与 `startReplay()` 调后者。淡出而不是硬切，是为了不让
正在响的采样在结算那一刻被掐出爆音。
