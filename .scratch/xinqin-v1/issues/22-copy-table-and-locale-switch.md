# 22: 文案表与语言开关——菜单画面双语

**What to build:** 玩家能切语言，而且第一眼看到的每一屏都跟着变。新建一张集中的文案表（一个键联合 + 中英两份字典，漏一条键编译即失败；带插值的句子是函数），加一个纯语言解析函数（浏览器语言 + 已存偏好 → 中文或 English，偏好为空即跟随系统）。设置里增加 `locale` 字段并**沿用现有设置键、不升版本号**，读取时非法值归空。入口两个：设置面板里一行语言切换、曲库标题右侧常驻「中 / EN」角标；切换后当前画面立即重渲染，并同步文档根元素的 `lang` 与页面标题。本票把**壳层菜单**（标题屏、曲库、设置、键位引导、暂停、致命错）的每一句中文迁进表并交付英文，含三首曲目的双语名（曲库行用短名、结算与引导用全名）、难度名、异色词缀名。曲目 id 与纪录键不随语言改变。

**Blocked by:** 无（可立即开始）

**Status:** resolved

**Branch:** `feat/v1.5-bilingual`

- [x] 文案表模块落地：键联合类型 + 中英两份字典（`Record` 穷举，漏键即 `tsc` 失败）；插值句子为函数
- [x] 语言解析纯函数覆盖分支：`zh-CN` / `zh-TW` / `en-US` / 空串 / 未知 × 已存偏好为空或显式值

- [x] 设置面板一行语言切换 + 曲库标题右侧「中 / EN」角标；切换即重渲染当前画面，`<html lang>` 与页面标题同步

- [x] 设置英文可用：音画偏移（含长段说明）、琴声音量、战斗音效音量、返回曲库

- [x] 不引入 i18n 库；不打包字体
- [x] 测试：字典键集对拍、语言解析分支、设置读写（先例 `settings.test.ts`）；原有 349 项全绿，`npm run build` 绿
