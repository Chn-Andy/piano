# 17: 进度轨——一首多长、我走到哪

**What to build:** 演奏全程能看出「还有多久」。屏幕顶部一条细时间轨：左端已过时间、右端总长（m:ss），
终章位置以朱砂点预告、到达即点亮；每次余韵后浮出「第 N / M 句」并在约两秒后淡出，最后一个乐句开始时
浮出「最后一句」。败局结算给出「走到 xx%，血尽」，胜局是 100%。曲库的难度格显示该谱面时长。
不引入大字倒计时（开演前那四拍倒计时原样保留）。这条轨是 HUD 锚位的唯一例外：其余状态读数仍在下半区
（ADR-0014），进度轨回屏幕最顶边——它是慢变量，不与判定抢注意力。

**Blocked by:** None（可立即开始）

**Status:** ready-for-agent

- [ ] 战斗中屏幕顶部有一条细进度轨（厚 ≤ 4px、左右各留边距、与顶边留白），左端读已过、右端读总长，均为 `m:ss`
- [ ] 终章时刻在轨上以朱砂点预告；跨过终章后该点变为点亮态
- [ ] 每次余韵触发后 0.3 秒内浮出「第 N / M 句」，约 2 秒后淡出，同一时刻只显示一条
- [ ] 最后一个乐句开始时浮出「最后一句」，与句序号一闪可辨（不叠字）
- [ ] 暂停/恢复后读数连续（时钟冻结，不跳变）；倒计时阶段轨为空白态，不出现乱数
- [ ] 败局结算显示「走到 N%」（按当时的谱面时刻与总长算，四舍五入到整数）；胜局显示 100%
- [ ] 曲库每个难度格显示该谱面时长（`m:ss`），与谱面总长一致
- [ ] 1440×900 与 800×600 下实测：进度轨、两侧蓄能槽、底部气血条、键位标签互不重叠，也不遮挡下落音符与判定线
- [ ] 纯函数测试覆盖：`t` 为负（倒计时）、0、中段、恰好末尾、超出末尾、无乐句谱面（句序号回退为不显示）
- [ ] 全量测试与构建绿；不改变任何对局数值（血量、咬线、充能、判定窗口、伤害、谱面）
