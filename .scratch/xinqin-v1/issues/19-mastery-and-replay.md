# 19: 掌握度与回放——「刚才那遍是我的」

**What to build:** 一局结束后能被听见、被留下。结算画面按本局数据判三档掌握度（初演 / 弹熟 / 精熟）
并给一张一屏可读的演奏卡（曲名、难度、评级、精度、最长连击、掌握度徽记、是否刷新纪录）；
提供「听我的演奏」——把本局**最后 20 秒**（含终章）重放一遍，玩家弹中的音叠在伴奏上，
漏掉的音不响。回放只在结算这一刻有效，离开即散，不写本地存储、不生成可回访的播放器。
曲库的难度格用三档徽记显示掌握度。掌握度只描述这一局发生过什么，不做任何专业承诺。

**Blocked by:** 18（伴奏声部）——回放的意义是把你的演奏叠在伴奏上重听，所以要等伴奏落地

**Status:** ready-for-agent

- [ ] 结算显示本局掌握度档位（初演 / 弹熟 / 精熟）；曲库对应难度格显示同档徽记
- [ ] 纪录结构扩展为存评级 + 最大连击 + 精度 + 失误数；读到旧版纪录不报错，按缺字段降级为只能判到「弹熟」
- [ ] 掌握度判定：胜局 + 任意评级 = 初演；评级 ≥ A = 弹熟；零失误且精度 ≥ 90% = 精熟；败局不入册（沿用现状）
- [ ] 结算页有「听我的演奏」：播放本局最后 20 秒（不足 20 秒则从头），玩家命中的音与伴奏同时响
- [ ] 回放中漏掉的音不发声（与静置对局同样安静），证明回放的是真实演奏而非补全
- [ ] 离开结算画面后回放不可再访问：不写本地存储、不出现任何入口（检查 local storage 无新增键）
- [ ] 演奏卡一屏可读，不出现横向滚动；1440×900 与 800×600 下都不裁字
- [ ] 纯函数测试覆盖：掌握度边界（0 命中 / 评级 C / A / S / 零失误 + 90% 双条件 / 有失误但精度 ≥ 95%）、
      旧纪录降级、回放裁剪（空演奏、短于 20 秒、跨终章、起点早于第一颗音的负偏移）
- [ ] 全量测试与构建绿；不改变任何对局数值与谱面
