# 04: 余韵与终章演出

**What to build:** 游戏的情绪核心：每个乐句结束自动触发「余韵」——本乐句累积的剑气一次性引爆成水墨收势演出，弹得越好演出越壮观；演出期间音符暂停、恢复无缝。歌曲高潮放大为「终章」：墨主登场，加强演出，击杀伴随墨点爆裂。受击顿帧、墨点粒子等水墨表现在此票成型，完成后截图即可当门面。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 乐句末自动触发余韵，触发点与规模分档由 Seam 1 单测断言（连击 + 判定质量 → 表现分）
- [ ] 演出期间音符暂停，结束后无缝恢复，节奏不乱
- [ ] 终章在歌曲高潮触发：加强演出 + 墨主登场，击杀有死亡爆裂
- [ ] 余韵规模分档肉眼可辨（弹好的乐句明显更壮观）
- [ ] 水墨视觉（剪影、顿帧、墨点粒子）成型，无外部素材依赖
