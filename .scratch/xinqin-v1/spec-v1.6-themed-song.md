# SPEC v1.6：主题曲《猪侠漫游记》

> 来源：2026-11-05 的 grill（`.scratch/xinqin-v1/grill-themed-song.md`，D1–D16）。
> 关联 ADR：0016（伴奏只承担和声）、0018（试作曲入库）、0019（本主题曲）、0005（水墨方向）。

## Problem Statement

《猪侠漫游记》进了曲库，但弹起来「太无聊」：只有钢琴还原的旋律与和声，原曲的鼓、贝斯、人声都不在，曲子失去了律动；战斗画面仍是通用的纸白 + 墨妖，和这首歌的绿野、粉猪、江湖气没有关系。玩家想要的不是另一首「钢琴练习曲」，而是**在这首歌里打一场属于它的斗琴**。

## Solution

把《猪侠漫游记》做成第一首**主题曲**：

- **medium / hard** 的战斗播放原曲全轨（含人声，人声比钢琴低 3dB）；玩家仍弹转谱的旋律，人声当引导。**easy 保持纯钢琴版**——easy 的 +2 半音移调与原曲 Bb 差 2 个半音，不能混。
- 战斗画面换成单曲主题色：浅绿纸（A）+ 亮粉强调（C）+ 金色点缀；**只改战斗 canvas**，菜单、结算、曲库、其他歌不动；倒计时里淡入。
- 墨妖换成**水墨可爱的山贼动物**：野猪 / 狐狸 / 狼，墨主是带刀疤与玫瑰的野猪王；行为、HP、定标完全不动，死亡仍是墨溅。
- 全轨局照常显示评级、照常入册；回放静音全轨；加载失败降级钢琴版。
- 公开发布（Pages + itch），署名「心心念念」。

## User Stories

1. 作为玩家，我想在中等/高级难度听到《猪侠漫游记》的原曲（鼓、贝斯、人声都在），以便弹起来像在歌里，而不是弹一首干巴巴的钢琴曲。
2. 作为玩家，我想在简单难度继续玩纯钢琴版，以便不因为原曲的调性与七白键移调冲突而听到刺耳的和声。
3. 作为玩家，我想让原曲人声当引导、钢琴仍是我弹的旋律，以便既能跟住歌，又保留「我在弹」的感觉。
4. 作为玩家，我想让人声比钢琴低 3dB，以便钢琴不被盖住、漏音仍听得见。
5. 作为玩家，我想在弹这首歌时看到浅绿纸、墨线和粉/金点缀的战斗画面，以便这场斗琴一眼就认得出是《猪侠漫游记》。
6. 作为玩家，我想主题色只在战斗画面出现，菜单、结算、曲库保持纸白，以便其他画面仍然是熟悉的心琴。
7. 作为玩家，我想主题色在倒计时里淡入，以便第一颗音符落下时舞台已经换好，不突然闪一下。
8. 作为玩家，我想在这首歌里看到水墨可爱的野猪/狐狸/狼山贼，以便敌人和歌的江湖气对得上。
9. 作为玩家，我想墨主是带刀疤与玫瑰的野猪王，以便歌词「刀疤带着玫瑰花」在战斗里有一个具体的形象。
10. 作为玩家，我想动物仍然会走、会蓄力、会扑咬、会死，以便可爱不牺牲战斗可读性。
11. 作为玩家，我想动物的 HP、伤害、推进、定标与原来完全一致，以便换皮不改变手感。
12. 作为玩家，我想全轨局的评级和纪录照常算，以便我在同一个掌握度阶梯里推进这首歌。
13. 作为玩家，我想「听我的演奏」回放只响我的钢琴与伴奏，以便回放听的是我这一遍，而不是原曲。
14. 作为玩家，我想全轨加载失败时仍能进游戏，以便网络不好时不至于卡在开局。
15. 作为玩家，我想在曲库的 medium/hard 格上看到「原曲」小签，以便知道哪几档带原曲、哪一档是纯钢琴。
16. 作为玩家，我想曲库简介写「主题曲 · 原创」，以便知道这首歌与三首公版曲不同。
17. 作为英文玩家，我想看到 *Theme song · Original* 与 *Full track* 的英文写法，以便英文模式不出现中文。
18. 作为开发者，我想主题是一份可复用的调色板数据，以便未来别的歌也能有自己的舞台，而不用再改一遍渲染器。
19. 作为开发者，我想全轨只在配置里声明适用难度，以便 easy 的键盘/移调规则不被临时特判污染。
20. 作为开发者，我想现有三首的谱面与像素输出保持不变，以便这次改动不回头破坏已验证的定标与视觉。

## Implementation Decisions

- **曲目配置**：`SongEntry` 增加两个可选字段——`backing`（音频文件、适用难度、增益）与 `theme`（`BattleTheme` 调色板 + 怪物皮肤）。只有《猪侠漫游记》填；其余三首不填，走默认值。
- **音频**：新增 Backing 模块，负责 fetch/decode/缓存一个 `AudioBuffer`，在 `roundStartAt`（谱面 t=0，音频时钟）启动一个 `BufferSource`；接音乐总线（受「琴声音量」控制）；暂停随 `AudioContext.suspend()` 冻结；结算时 `fadeOutMusic` 的同时停掉音源；回放前确保音源已停（回放只响钢琴 + 伴奏）。全轨增益在曲目配置里，默认 0.5；人声在导出资产时已比器乐低 3dB。
- **时间原点**：全轨从**原曲 2.776s** 起截，而不是转谱的 2.8s trim——谱面 t=0 = 第一颗音 − `LEAD_IN_SECONDS`；按 2.8s 截会让每一颗音与全轨错开 24ms。
- **主题色**：`BattleTheme` 是纯数据（纸、纸高光、墨、深墨、强调粉、金、琴心、异色三色、怪物皮肤）。渲染器逐帧在默认调色板与主题调色板之间插值；默认主题的字段与旧常量逐一相同，现有三首像素不变。主题只作用于战斗 canvas；`drawBackdrop` 强制默认主题。
- **淡入**：倒计时开始（`roundStartAt − COUNT_BEATS × BEAT_SECONDS`）起 0.8s 插值到主题色；倒计时结束前已完全换好。
- **动物皮肤**：渲染层按 `MonsterKind` + `monster.id` 选形貌；墨妖按 id 哈希分到野猪/狐狸/狼，墨主固定刀疤野猪。复用现有 `MonsterAnim`（步态、起伏、蓄力、挥砍）；`drawMonster` 的受击闪示、缩放、alpha 不变。死亡仍是 `inkSpray`。
- **纪录**：不新增模式判定；全轨局走现有 `recordResult`，照常写最佳与掌握度。
- **曲库**：`backing.difficulties` 含 medium/hard 时，对应难度格渲染「原曲」小签；easy 没有。简介改「主题曲 · 原创」/「Theme song · Original」。文案进集中表。
- **失败降级**：`backing.load` 返回失败时只记一条 console 警告，战斗按纯钢琴开始；不弹窗、不阻塞。
- **发布物**：全轨进 `assets/songs/`，随 Pages/itch 发布；README 素材段与 itch 描述署名「心心念念」。

## Testing Decisions

- **好的测试**：只断言外部行为与数据契约，不测 canvas 像素、不测 Web Audio 内部节点。
- **纯数据契约**（新测试，放在曲库索引旁）：`zhuxia` 的 backing 只含 medium/hard、gain 在 0..1、theme 存在；其余三首无 backing/theme；主题纸/墨的对比度达到可读阈值（相对亮度比 ≥ 4.5）。
- **既有回归**：`npm test` 全量（当前 392 项）+ `npm run build`；定标矩阵 48 项不变，现有三首谱面逐字节不变。
- **浏览器实测**：`?song=zhuxia-manyouji&chart=medium&auto=perfect` 跑到结算——检查 `__xq` 的 phase/perfect/miss、主题截图（浅绿纸、粉笔、动物）、全轨读取状态；再跑一首旧歌截图对照纸白未变；曲库截图确认「原曲」小签只在 medium/hard。
- **先例**：曲库/文案契约测试同 `src/i18n/copy.test.ts`；谱面结构测试同 `src/converter/convert.test.ts`；浏览器实测同 v1.4/v1.5 的 `?auto` 钩子流程。

## Out of Scope

- easy 的全轨（+2 半音冲突，不做变调）。
- 逐音 ducking / 人声音量滑条 / 主题开关。
- 给其他歌做主题或全轨。
- 主题结算卡、曲库主题化、暂停面板主题化。
- 用视频插画做背景/立绘；动物仍是程序绘制的水墨剪影。
- 转谱的人工精修（本轮仍是草稿级转谱）。
- 原创曲的版权登记/商用授权审查（用户已确认公开使用并署名）。

## Further Notes

- 全轨资产由 Demucs 四轨合成：drums + bass + other + vocals×0.708，限幅后 160k MP3；从 2.776s 截 138.2s。
- 人声一进来，转谱的偏音/偏时会比纯钢琴版更明显；试玩时优先听「钢琴与人声是否打架」，必要时先修 MIDI 再改主题。
- 主题调色板的默认值必须与旧常量逐字段相同；这是「现有三首不变」的唯一保证。
- 曲库第四行在 720p 下刚好放得下；「原曲」小签加在难度名旁，不能再增高一行。
