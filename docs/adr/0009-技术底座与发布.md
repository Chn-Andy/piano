# 技术底座与发布

技术栈：Vite + TypeScript + 原生 Canvas 2D，不用游戏引擎、不用前端框架。水墨特效（剪影、墨点粒子、路径变形）的规模 Canvas 2D 完全胜任，依赖最少、时序可控性最强。音频走 Web Audio API，钢琴音色用采样（免费授权采样包按需加载），战斗音效合成；游戏主时钟跟随 `audioContext.currentTime` 而非 rAF 时间戳，实现阶段另立 ADR 记录细节。

拒绝 Phaser/Pixi：场景规模（一张战斗画面 + 少量粒子）不足以抵销引擎抽象的调试成本；拒绝 React 类框架：60fps 逐帧渲染的画布里 DOM 思维是负资产。

发布：产物为纯静态文件，GitHub Pages 与 itch.io 双发，一份产物两处上架，零后端。
