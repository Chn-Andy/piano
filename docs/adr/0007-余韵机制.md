# 余韵机制

节奏游戏中玩家视线全程钉在下落音符上，看不到自己的攻击。解法不是加大招按钮，而是让歌曲结构当导演：谱面按乐句划分，每个乐句末尾的天然换气口处自动触发「余韵」——短暂暂停音符下落（约 0.5–1 秒），将该乐句累积的剑气一次性引爆成收势演出，规模随该乐句演奏表现（连击与判定质量）缩放；歌曲高潮处放大为加强版「终章」。

拒绝玩家手动触发的大招：钢琴键位布局（ADR-0006）下玩家双手全在琴键上，高级难度无空余手指，且"何时放"的决策与弹琴抢注意力；自动触发让音乐自己掌握爆发节奏，"欣赏杰作"成为弹得好的奖励而非操作负担。

后果：谱面格式必须编码乐句边界与休止窗口；反馈系统分两层——乐句内反馈走余光可读（血条、顿帧、墨点），余韵/终章是仰望时刻。

**增补（2026-10-27）**：新增「琴心」蓄能——连击为琴心槽充能，充满自动释放全场爆发「琴心通明」。本 ADR 的核心原则（不加玩家触发的大招按键）不变：琴心与余韵同为自动释放，区别在绑定——余韵绑定乐句结构，琴心绑定连击表现，可在乐句中途爆发。充能与释放均为模拟器纯函数；连击中断只停止充能、不清空已充之能。
