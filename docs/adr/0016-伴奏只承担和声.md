# 伴奏声部只承担和声，旋律永远归玩家

每份谱面可以带一条**伴奏声部**：由游戏在音频主时钟上自动演奏（ADR-0010 的 lookahead 调度器），内容是源曲里的左手/和声/低音。**伴奏永远不弹主旋律**——旋律只在你按键时响。漏掉一颗音，旋律就缺一颗（配着仍在进行的和声，听得出来是哪一处），而不是被伴奏悄悄补上。伴奏的音频全部由同一套钢琴采样重放，不引入常驻音轨、不新增素材。

理由：这条边界同时支撑两件事，而它们会互相拉扯。「我弹了一首名曲」需要一个**连续成立的音乐身体**——只有自己稀疏的几个音时，曲子是断的、单调的，玩家听不出这是卡农（现在的实际听感）。但判定反馈需要**漏音可听**——若伴奏把整首都弹了（含旋律），你把手指从键盘上拿开也和弹对一样好听，Perfect/Good/Miss 就退化成血条上的数字，一整条反馈链断掉。和声骨架是唯一同时满足两者的切法：音乐不断，但 melody 的完整性始终是你的账。全曲代弹因此被明确拒绝——它用「更好听」换走了「你弹的」。

后果：谱面数据契约新增伴奏声部（一个时刻 + 音高的序列，可与主旋律共用转换器的源曲读取路径），生成必须确定性、可测试；伴奏的密度与力度按难度给（简单可以只留低音与根音，高级补齐内声部），但不参与判定、不参与战斗伤害，也不改 `docs/calibration.md` 的任何定标值。卡农的 fixture 只有单轨 138 个音、没有可拆的伴奏声部，因此它需要先换一份多轨公版素材；换不到就只用一层合成的低频铺底，不能拿主旋律冒充伴奏。
