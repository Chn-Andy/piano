# 掉血归因重构：怪物到位才造成威胁

v1 中 miss 直接触发墨妖反击扣血——因果即时但抽象，且怪物站桩不构成空间压力，试玩反馈"怪物太差"。修订为：miss 不再直接扣血（保留剑气扑空动画与怪物突进的可见反馈），怪物成群自战场深处向琴阵推进，抵达琴阵后每两拍攻击一次（每口约 10 血，定标常量）直至被杀。玩家血量威胁完全来自怪物到位；miss 的代价是伤害输出下降→墨潮逼近，因果结构可见。

这是对 ADR-0004 战斗映射中「miss=怪物攻击玩家掉血」的部分取代；命中=伤害、连击=倍率、和弦=重击、胜负条件（撑到歌末且清空全场含墨主为胜）继续有效。灵感来自用户提出的"打丧尸式"推进防御。
