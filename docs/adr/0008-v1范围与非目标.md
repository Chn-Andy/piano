# v1 范围与非目标

v1 范围：3 首公版曲目 × 3 难度——卡农（入门）、致爱丽丝（经典识别度）、春江花月夜（水墨点题收官）；怪物仅一种原型「墨妖」（体型/墨色两个变体），每场斗琴末尾一个 boss「墨主」；首次进入 30 秒键位引导；结算画面只显示评级（S/A/B/C）、最大连击与伤害统计；设置含音画偏移校准滑条；UI 中文。

明确的非目标（v1 不做）：独立分数系统、账号、云存档、排行榜、任何后端、乐句检查点（血空即败、整首重开，见 ADR-0004 的斗琴完整性）、第二种怪物原型、触屏适配（ADR-0002）。

理由：单人几周内可完成且每个部分都拿得出手；墨妖单原型靠水墨风格的体型与墨色区分变体，是范围控制的关键杠杆。

---

**附注（2026-10-24，代码审查追认）**：结算画面实际还显示判定计数（完美 / 良好 / 失误），超出上文"只显示评级、最大连击与伤害统计"的文面。判定计数为审查时追认扩入结算显示范围：评级公式是 accuracy 制（Good 折算 0.6，见 rating.ts），计数向玩家解释评级来源——没有它，"为什么精度很高却只得 A / S 的双门槛差在哪"不可读。此为显示层的扩张，不改变 v1 非目标：仍无独立分数系统，判定计数不构成分数。
