# 每首歌都是一场斗琴

战斗不是附加模式而是游戏本体：每首歌就是一场战斗，怪物随歌曲段落出场。战斗映射规则：音符命中=对怪造成伤害，连击数=伤害倍率，miss/漏音符=怪物攻击玩家掉血，和弦音符=重击；玩家血空或歌毕怪未清完为失败，撑到歌末且清完怪物为胜利。

理由：项目的差异化亮点就是"琴音化剑气杀怪"（灵感来自《功夫》盲琴师），它把节奏游戏抽象的分数反馈换成有画面感的直接反馈，并给每首歌一个比"分数更高"更强的目标；先做无战斗版再缝上去会导致视觉布局返工两次，而反方向（战斗游戏加"关闭怪物"选项变纯节奏模式）成本极低。

约束：玩家视线全程钉在下半区下落音符上，怪物必须活在画面上半区、以大状态可读（血条、受击顿帧、死亡爆裂），不能依赖细碎动画。
