# 演奏幻想是主叙事，不动战斗谱面

把「像真的弹了一首世界名曲」立为本作的**北向指标与主叙事**：凡新增功能先过一句「它让『我弹了这首曲子』更真了吗」；墨潮守线的战斗（ADR-0004/0011）继续当张力外壳，其谱面与定标**不动**。原曲保真（原音高、双声部、真实密度）**明确不做**——这个幻想靠听感与服务兑现，不靠谱面忠实度（2026-10-31 定，见文末附注）。

理由：用户的目标不是更高分，而是「我一直想学钢琴，通过这个游戏让我像是会弹」。而现有战斗谱面是为**可打性**做的改编——简单难度整曲移调到白键、黑键折进上方白键（`converter/convert.ts` 的 `diatonicLane`），中高难度把音高按 ±12 八度折叠进键域（`chromaticLane`）；卡农简单 82 音 / 175 秒 ≈ 每 2.1 秒按一键。按现在的谱面，玩家听到的音高与密度都不是原曲——这条事实先摆出来，是为了避免一个错误结论：以为「像弹了一首名曲」必须靠提高谱面忠实度。用户看过这些数字后的回答是：他要的是**感觉**自己会弹，不是音高与原谱一致。于是这个幻想不该压在谱面改造上（那会推翻三曲 × 三难度 × 三玩家模型的 36 项定标），而应该压在**听感与服务**上：曲子始终完整（伴奏声部，ADR-0016）、你知道自己走到哪儿（进度轨）、一局结束后能被听见与留下（回放、掌握度）。

后果：任何新 feature 的验收要回答「它让『我弹了这首曲子』更真了吗」，但**不许**拿谱面保真度当答案。战斗档的谱面无变更，`docs/calibration.md` 的定标记录继续有效。这条不改变 ADR-0001 的判定口径，也不改变 ADR-0008 的非目标清单——它只回答「我们为谁的满足感负责」。

**附注（2026-10-31，访谈第 3 轮）**：原先写的是「若要做原曲保真，另开一档」，用户看过素材与谱面事实后改为**保真档不做、连设计票也不留**：他要的是「感觉自己会弹了」，不是「弹的和原谱一致」。于是演奏幻想被重新定义为三件可交付的东西——曲子始终完整（伴奏声部，ADR-0016）、你知道自己走到哪儿（进度轨）、一局结束后能被听见与留下（回放、掌握度）。改写理由记在这里，避免后人不明就地把它当作「迟早要做的技术债」。
