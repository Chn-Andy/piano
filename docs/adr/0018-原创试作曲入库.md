# 原创试作曲入库：视频音轨转谱的《猪侠漫游记》

曲库加入第四首《猪侠漫游记》（用户提供的豆包 AI 生成歌曲，署名「心心念念」），三难度谱面由**视频音轨自动转谱**得到：Demucs 分离人声 → pyin 取基频 → 音符切分 → 量化到十六分音符网格；和声由非人声轨的 chroma 做三和弦模板匹配，每两拍一个和弦。这是 v1.6 的试作，不是正式发行内容。

为什么值得破例：ADR-0003 把曲库边界钉在公版，理由是版权与「名曲」识别度；这首歌是用户自己的作品，版权风险由用户承担，而它证明的是另一件事——**一首只有音频、没有 MIDI 的歌，能不能变成可弹的谱面**。心琴的管线一直是 MIDI→谱面，豆包/海绵都没有 MIDI 或分轨导出，自动转谱是唯一可走的路。做出来若能在游戏里认出这首歌，「曲库可以扩张到原创/自制歌曲」就从设想变成了可验证的事实。

为什么玩家只弹旋律：转谱出的和声轨用来做伴奏材料，不塞进玩家谱面。MIDI 轨名约定 `accompaniment` 的轨由转换器跳过（`ACCOMPANIMENT_TRACK_NAME`），但仍作为第二条旋律轨供 `buildAccompaniment` 取和声（ADR-0016 的边界不变：伴奏永远不弹主旋律）。这样玩家弹的是人声旋律，和弦由伴奏声部自动奏出；若把三和弦也塞给玩家，中等难度会密到「普通玩家也能守线」，破坏定标性质。现有三首 fixture 没有同名轨，谱面逐字节不变。

## 后果

- **非公版曲目入库**。ADR-0003 的「扩张永远以公版边界为限」被这一首试作打开一个口子；发行前须由用户确认授权，且不能把「名曲」当作它的卖点。曲库简介写「童趣 · 原创」而不是「名曲」。
- **转谱质量是草稿级**。人声分离、基频跟踪、切分与量化都会错音/漏音；它听起来应该是这首歌，但不是一份可当作乐谱的转谱。要正式收，得换一份人工校对的 MIDI，或至少逐段试听修订。
- **游戏里是钢琴版**。不引入原曲音轨（ADR-0016），原唱不会出现；玩家听到的是自己弹的旋律加自动和声。
- **定标矩阵扩到十二张**。四曲 × 三难度全部跑四条性质（完美/认真全胜、普通全败、静置被咬空），`docs/calibration.md` 与测试描述同步；现有三首的谱面与定标常量一个都没动。
- **发布物待定**。v1.5 的 itch 页与截图仍是三首；这首进正式发行前要重拍曲库截图、改商店页与 README 的曲目数。
