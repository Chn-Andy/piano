# 主题曲：全轨伴奏、单曲主题色与可爱动物墨妖

《猪侠漫游记》作为第一首**主题曲**：medium / hard 的战斗里播放原曲全轨（含人声），战斗画面换成浅绿纸 + 亮粉点缀的单曲主题色，墨妖换成水墨可爱的山贼动物（野猪 / 狐狸 / 狼），墨主是带刀疤与玫瑰的野猪王。easy 仍是纯钢琴版——easy 会把全曲 +2 半音移到 C（七白键），原曲是 Bb，全轨一放就差 2 个半音，这是硬冲突，不是混音能救的。

**为什么破 ADR-0016 的「不引入常驻音轨」**：用户听完四种预览后选了全轨，理由是纯钢琴版「弹起来太无聊」——鼓、贝斯、人声都不在，歌的律动没了。全轨的代价说清楚后由用户接受：人声在唱同一条旋律，漏音会被盖住，人声还会变成 timing guide。判定仍只数按键，评级仍按精度算；用户明确选择**照常入册**，不另立「演出模式」。人声固定比钢琴低 3dB，不做逐音闪避。

**为什么主题只改战斗画面**：菜单、曲库、结算是纸白的壳，战斗是 canvas。单曲主题只换 canvas 的调色板，壳层不动——玩家的「这是同一款游戏」的连续感靠壳层维持，主题曲的特殊感靠战斗的绿纸、粉笔和动物。主题在倒计时里淡入，结算幕布出现时已被盖住，不额外做主题结算卡。

**为什么是水墨可爱动物而不是彩色卡通**：用户先要「可爱风」，但彩色卡通会和 ADR-0005 的水墨材质割裂；折中是**材质仍是墨、造型变可爱**——圆身、短腿、纸白大眼、粉腮红，行为/HP/定标完全不动，死亡仍是墨溅。墨主用歌词「刀疤带着玫瑰花」里的刀疤野猪，把歌和战斗接上。

**调色板怎么接线**：渲染器原来的纸/墨/深墨是两个模块常量，直接换两个值会让为旧底色调过的强调色、判定闪示与异色失去对比。改成 `BattleTheme` 调色板对象，逐帧在默认色与主题色之间插值；默认主题的色值与旧常量逐字段相同，现有三首的像素输出不变。主题只作用于 canvas，DOM 壳不读它。

## 后果

- **新增常驻音频资产**：`assets/songs/zhuxia-manyouji.mp3`（约 2.7MB，160k，按谱面时间原点 2.776s 截到 138.2s）。发布产物变大；GitHub Pages 与 itch 都带这首歌，署名「心心念念」。
- **全轨只在 medium / hard**：`SongEntry` 新增可选的 `backing`（文件、适用难度、增益）与 `theme`（调色板、怪物皮肤）。easy 走原路径，不受影响。
- **全轨加载失败降级**：fetch/decode 失败时退回纯钢琴版，不阻塞开局；回放静音全轨（「听我的演奏」仍是自己弹的）。
- **纪录照常**：全轨局与钢琴局在同一个 mastery 阶梯里比较；人声作为 timing guide 的难度下降被接受（用户 Q10 改选 c）。
- **转谱质量仍是草稿级**：人声一进来，转谱的偏音/偏时会比纯钢琴版更明显；发行前仍建议人工试听修订。
- **测试面**：定标矩阵不变（四曲 × 三难度 48 项）；新增的是纯数据契约（backing 难度、主题字段、纸/墨对比）与浏览器实测，不改战斗常量。


**修订（2026-11-05，用户试听反馈）**：初版把原曲人声压到比钢琴低 3dB，实机里人声被玩家的琴声盖住，听起来不像同一首歌。新的混音口径：全轨资产内人声 +2.8dB、伴奏总音量 0.64（相对初版 0.5 约 +2.1dB）、全轨局玩家琴声 0.72（约 −2.9dB），人声相对琴声提高约 7.8dB。人声仍承担 timing guide，评级与入册口径不变。若仍觉得琴声太抢，先调 `FULL_TRACK_PIANO_GAIN`，不要动判定窗口。
