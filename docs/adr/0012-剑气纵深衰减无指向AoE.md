# 剑气为纵深衰减的全屏 AoE，无指向决策

多怪物引入后存在指向问题：节奏游戏玩家视线钉在下落区，无法手动选目标；按音区对位映射（高音打右边的怪）增加感知负担，且谱面音高分布由乐曲决定、不保证策略意义。决定：剑气为全屏纵深攻击——每次命中打击全场所有怪物，伤害随纵深（离琴阵距离）逐级衰减（衰减比与纵深上限为定标常量），前排承伤最多、后排递减；怪物横向散布仅作视觉变化，不构成目标语义。

异色音符的效果语义随此模型：寒音全场击退并减速；毒音附加于最前怪物（承伤最多者）；爆音对最前与次前重击。异色音符由转换器确定性编排入谱面（同曲重开布局一致，公平且可测试），频率约 5–8%，不用运行时随机。

拒绝方案：单列纵队集火最前（用户裁定视觉单调）；按音区选目标（注意力过载、策略性无谱面保证）。
